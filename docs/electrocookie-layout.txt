WIRE EXIT SUMMARY
═════════════════
→ Pi Zero:     TX (R3), RX (R4), GND (R5), 5V+GND (R26)
→ Keypad:      Rows 0-3 (R6-R9), Cols 0-2 (R11-R13)
→ Hook switch: GP10 (R16), GND (R15)
→ L298N:       IN1+IN2+GND (R23 header), 12V+GND (R24 terminal)
→ LM2596:     12V IN+GND (R25 terminal) ←→ 5V OUT returns to R1 right rail
→ LED:         GP14 (R21) → 220Ω → LED → GND rail
→ Transformer: NOT on board (connects to L298N OUT1/OUT2)
→ Bell coil:   NOT on board (connects to transformer red wires)
